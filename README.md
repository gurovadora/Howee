# Howee

Mobile pet project built with Expo, React Native, and TypeScript.

## Getting started

Install dependencies:

```bash
npm install
```

Start the app:

```bash
npm start
```

Then open it in a simulator, emulator, or Expo development build.

## Scripts

- `npm start` - start Expo dev server
- `npm run ios` - run on iOS simulator
- `npm run android` - run on Android emulator
- `npm run web` - run web preview
- `npm run typecheck` - check TypeScript
